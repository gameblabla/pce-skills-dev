# 07-psg-two-tones

**Category:** Audio

Two PSG channels with distinct frequencies, using the same tiny wave shape.

Build with `make`; the output is `build/07-psg-two-tones.pce` (HuCard). This single-file example uses the local LLVM-MOS PCE SDK. There is deliberately no screen initialization or text; inspect the `volatile` variable in a debugger if one is declared.
