# 13-vdc-scroll-x

**Category:** Graphics

Scroll a simple tiled background horizontally.

Build with `make`; the output is `build/13-vdc-scroll-x.pce` (HuCard). This single-file example uses the local LLVM-MOS PCE SDK. This sample alone uses video registers; no audio code is initialized.

**Timing:** Busy-loop waits are approximate and not suitable for precise music, PCM sample rates, or production raster effects.
