# 22-vdc-vblank-irq

**Category:** Graphics

Count VDC VBlank interrupts for frame timing; no text.

Build with `make`; the output is `build/22-vdc-vblank-irq.pce` (HuCard). This single-file example uses the local LLVM-MOS PCE SDK. This sample alone uses video registers; no audio code is initialized.
