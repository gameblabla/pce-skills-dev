# 35-psg-noise-burst

**Category:** Audio

**Audio:** Play a short noise burst on PSG channel 4, then stop it.

**Audio-only:** no VDC, VCE, tile, text, font, sprite, or screenshot code. CPU delay loops do not give exact audio timing.

Build with `make`. Run with `make run` or `make debug` (the shared wrapper configures the emulator). HuCard target; optional expansion hardware is noted by the example name.
