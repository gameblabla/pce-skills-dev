# 39-vdc-vram-copy

**Graphics:** Upload exactly one 8x8, 4bpp tile (32 bytes) to VDC VRAM.

**Graphics-only:** no PSG or audio setup. A debugger-only VRAM or palette test may intentionally show no picture.

Build with `make`. Run with `make run` or `make debug` (the shared wrapper configures the emulator). HuCard target; optional expansion hardware is noted by the example name.
