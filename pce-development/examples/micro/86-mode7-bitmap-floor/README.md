# 86-mode7-bitmap-floor

**Category:** Graphics

A **128×128, 16-colour, perspective-textured racing ground**, inspired by the earlier Saber Rider PC Engine Wolf3D/Mode 7-style track. This is **not** a projected circle. The source is a repeating 128×128 virtual ground map generated by `floor128_texel()` with curved asphalt, yellow centre markings, red/white kerbs, grass and roadside speckles. Each projected output scanline has a perspective depth and affine texture coordinates.

Use **LEFT/RIGHT** to rotate the camera in 16 steps, **UP/DOWN** to move forward/backward in the camera direction. All pixels use four VDC bitplanes; there is no sound, text, sprites, or CD dependency. Compile with `make`, test with `make run`. The example is deliberately simple and redraws only on button presses with the BG off; it does **not** target real-time 60fps.

This version uses **unique 8×8 planar patterns** to show a full 128×128×4bpp image without requiring an 8 KiB CPU RAM framebuffer. PCEdev's faster **pseudo-bitmap** trick instead packs *two* 4-bit logical pixels into each BAT character index with 256 prebuilt pair tiles; the original Saber Rider version used that pair-character strategy and sampled 19 strips into alternating BAT pages. Those techniques require more sophisticated BAT arrangement/raster handling and have intentionally not been disguised as an equivalent implementation here.

Sources: [old Saber Rider floor](https://github.com/gameblabla/SaberRiderStarSheriffUnOfficial/blob/174e90dc9262/src/platform/pce/floor_pce.c), [sampler assembly](https://github.com/gameblabla/SaberRiderStarSheriffUnOfficial/blob/174e90dc9262/src/platform/pce/floor_sample.S), [PCEdev bitmap mode](https://pcedev.wordpress.com/2015/12/10/pce-bitmap-mode/), [PCEdev Wolfenstein notes](https://pcedev.wordpress.com/2015/11/25/wolfenstein-3d-on-the-pc-engine/).

**Hardware nuance:** Base PC Engine background pixels use 16 colours per palette. SuperGrafx has two VDCs and can combine indexed colour planes for **up to 241 visible colour combinations** under the pseudo-bitmap scheme discussed by PCEdev, sometimes loosely called a "256-colour" technique. Neither machine has native SNES Mode 7 affine hardware.
