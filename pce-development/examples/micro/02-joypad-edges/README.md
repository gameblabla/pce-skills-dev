# 02-joypad-edges

**Category:** Input

Detect fresh presses without adding an on-screen HUD.

Build with `make`; the output is `build/02-joypad-edges.pce` (HuCard). This single-file example uses the local LLVM-MOS PCE SDK. There is deliberately no screen initialization or text; inspect the `volatile` variable in a debugger if one is declared.
